# БатылBot 🤖

Балаларға арналған интерактивті көмекші веб-қосымшасы.

## Мүмкіндіктері:
- Қорқыныш түрлерін таңдау (қараңғылық, көпшілік алдында сөйлеу, жалғыз қалу)
- Қорқыныш деңгейін бағалау (0-ден 4-ке дейін)
- 3D суреттермен көрнекі жаттығулар
- Батыл ойларды таңдау
- Қайта бағалау және нәтижені шығару
- Компьютерде де, ұялы телефондарда да толықтай ыңғайлы әрі жылдам жұмыс істейді (қайта ойнау мүмкіндігімен)

## Деплой:
Vercel арқылы автоматты түрде `index.html` файлы негізінде іске қосылады.
